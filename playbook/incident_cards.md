# Incident cards

> SIMULATED data (seed 42). Not Emerging Travel Group data. Generated by `src/build_playbook.py` from `data/output/sim/incidents.csv` and `dq_issues.csv`.

One card per event found by the monitoring. Same format every time, so the commercial team can read it in one minute: what happened, the proof, the impact in euros, what to do, who owns it, how we follow it.
Impacts are margin in EUR from the event start to 31 Oct 2026 (negative = margin lost).

## E1 · Supplier net-rate increase

| | |
|---|---|
| **What happened** | Bedbank C raised its net rates in Spain from 15 Jun 2026; selling prices did not move |
| **Evidence** | Margin rate on Bedbank C x Spain 8.5% -> 2.2%; bookings/day 10.5 -> 10.4 |
| **Impact (EUR)** | -32,556 |
| **Recommendation** | Re-route Spain demand to Direct contracts / Bedbank B where cheaper; renegotiate or raise sell rates +5% on affected hotels |
| **Owner** | Supply / contracting |
| **Follow-up** | Daily margin rate on Bedbank C x Spain back above 7% |

## E3 · Currency effect (real TRY depreciation, ECB rates)

| | |
|---|---|
| **What happened** | Turkish partners pay in TRY; the lira lost value against the euro (ECB reference rates) |

| **Follow-up** | Constant-FX sales line in the daily report |
